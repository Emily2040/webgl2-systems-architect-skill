# 04 - 被写体監査と視覚階層 (ja)

## Purpose

視覚的な対象を優先順位付きのエンジニアリングチェックリストへ変換し、シェーダー命令数とパスバジェットを観察者が最初に認識する特徴へ配分する。微細ディテールより先にシルエットを確立する。

## When to load

視覚的説得力、マテリアル表現、または負荷逼迫時の機能削減順序が重要となる `architecture` および `review` タスクでロードする。

## Inputs

- 被写体の説明またはリファレンス画像
- カメラフレーミング（クローズアップ、ミディアム、ワイド環境、UI）
- プロジェクト分類および利用可能なフラグメント/頂点バジェット

## Rules

### 1. 被写体を 5 つの観察レイヤーに分解する

1. **主要シルエットとプロポーション**（マクロな外形比率、地平線や輪郭の読みやすさ）
2. **二次構造**（主要な解剖学的平面、建築の継ぎ目、地形の尾根階層、UI ウィジェット境界）
3. **マテリアル応答**（ラフネス対比、フレネルリム、SSS 近似、異方性ハイライト）
4. **ライティングと奥行き分離**（キー/フィル比、コンタクトシャドウ、空と地面の半球分離、大気フォグ）
5. **モーションと時間的安定性**（サブピクセル AA、スペキュラエイリアシング抑制、カメライージング）

### 2. 視覚特徴を P0・P1・P2 にランク付けする

- **P0 - アイデンティティ決定特徴（全ティア必須）**：欠けると被写体として成立しない要素（顔面バストの頭蓋・顎比率と眼窩の奥行き、地形の主稜線、UI 文字の SDF エッジ）。
- **P1 - マテリアル・奥行き補強（`mid` / `high` ティア）**：マルチタップ AO、ソフトシャドウ半影、デュアルローブスペキュラ、ディテール法線。
- **P2 - ラグジュアリー演出（フレーム時間に余裕がある `high` ティア限定）**：毛穴のマイクロディスプレイスメント、ボリューメトリックライト、色収差、フル解像度 SSR。

### 3. バジェット逼迫時の削減順序を固定する

フレーム時間が `gpuBudgetMs` を超過した場合は以下の順で負荷を落とす：
1. P2 マイクロディテールパスと追加タップを無効化する。
2. 補助パス（AO、ブルーム、フォグ）を軸方向 `0.5x` 解像度（ピクセル数 `0.25x`）へ落とす。
3. 高 DPI モバイル端末で `targetDPR` を `1.25〜1.5` にクランプする。
4. P1 シャドウ/AO のサンプル数を削減する。
5. P0 のシルエット比率や主光源の立体感は最後まで維持する。

## Failure modes

- 頭蓋や顎のシルエットが崩れているのに毛穴ノイズに 40 ALU 命令を費やす
- モバイルで 30 FPS を割っているのにフル解像度の P2 ポストプロセスを維持する
- 具体的な P0/P1 特徴とコストを示さず「映画のような質感」と記述する

## Output contribution

`deliverables`（P0/P1/P2 機能表と削減順序）、`decisions`、視覚面の `risks` を出力する。

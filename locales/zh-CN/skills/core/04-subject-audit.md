# 04 - 视觉主体审计与特征层级 (zh-CN)

## Purpose

将视觉目标拆解为按优先级排序的工程核对表，使宝贵的片元预算优先服务于观者最先感知的结构特征。先立轮廓，再添细节。

## When to load

在涉及视觉可信度、材质表现或性能降级裁剪顺序的 `architecture` 与 `review` 任务中加载。

## Inputs

- 视觉主体描述或参考图
- 镜头景别（特写、中景、远景环境、正交 UI）
- 项目类别与可用片元/顶点预算

## Rules

### 1. 将主体拆解为五个可观测层级

1. **主轮廓与比例**（宏观包围体、长宽比、天际线或外轮廓）
2. **次级结构**（主要解剖转折面、结构接缝、地形山脊层级、控件边界）
3. **材质响应**（粗糙度对比、菲涅尔边缘、次表面散射近似、各向异性高光）
4. **光影与深度分离**（主辅光比、接触阴影、天地半球反射、大气雾效）
5. **运动与时间稳定性**（亚像素抗锯齿、高光闪烁抑制、相机阻尼）

### 2. 严格划分 P0 / P1 / P2 特征优先级

- **P0 - 身份决定性特征（全档位必保）**：缺失则主体无法识别（如人像头颅与下颌比例、眼窝深度；地形主山脊起伏；UI 字体边缘锐度）。
- **P1 - 材质与深度强化（`mid` 与 `high` 档启用）**：多步 AO、软阴影半影、双瓣高光、细节法线。
- **P2 - 锦上添花细节（仅在 `high` 档且帧耗时充裕时启用）**：皮肤毛孔微置换、体积光束、色散、全分辨率屏幕空间反射。

### 3. 预算超支时的固定裁剪顺序

优先裁剪高成本微细节：
1. 关闭 P2 微细节通道与额外采样步数。
2. 将 AO、Bloom、体积雾等辅助通道降至 `0.5x` 轴向分辨率（`0.25x` 像素数）。
3. 将高分屏移动端的 `targetDPR` 钳制到 `1.25-1.5`。
4. 降低 P1 软阴影/AO 采样步数。
5. 绝不为了节省少量 ALU 指令而破坏 P0 宏观比例或主光源体积感。

## Failure modes

- 在头骨或下颌轮廓失真的情况下耗费数十条指令计算毛孔噪声
- 移动端帧率跌破 30 FPS 时仍保持全分辨率 P2 后处理
- 用“电影级画质”等空洞词汇代替具体的 P0/P1 视觉线索与通道成本

## Output contribution

填充 `deliverables`（P0/P1/P2 特征表与裁剪顺序）、`decisions` 与视觉可信度 `risks`。

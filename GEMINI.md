# GEMINI.md

Treat this repository as a routed WebGL 2.0 engineering skill. Stay grounded in measurements.

1. Read `SKILL.md`.
2. Load `references/00-orchestrator.md` (or `locales/{zh-CN,ja,ko}/references/00-orchestrator.md` for CJK tasks).
3. Run triage through `skills/core/01-triage.md`.
4. Pull only the modules mapped in `registry/module-map.json`.
5. Keep async and parallel claims honest by separating Web Worker asset preparation, async shader link polling, and staged PBO readbacks from serial single-context WebGL draw submission.
6. Apply `registry/forbidden-slop.json` before finalizing output.

# Example Input - Face Raymarch

I want a WebGL 2.0 face-bust renderer for mobile Safari and desktop Chrome that maintains 60 FPS on a phone-sized viewport while preserving credible craniofacial silhouette, eye-socket depth, and lip/cornea material separation.
It should look anatomically credible from medium-close framing, not just like a smooth mannequin.
I expect SDF raymarching, soft shadows, and ambient occlusion.
I care about a stable startup, clear feature priorities, and a fallback path for lower-end mobile GPUs.
Please design the renderer and note what can run in parallel or asynchronously. Keep startup fast.
